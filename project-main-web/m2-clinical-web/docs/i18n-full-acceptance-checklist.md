# M2 全量多语言验收清单

> 适用语言：`zh-CN` / `en` / `pt-BR`  
> 验收原则：切换后当前页与跳转页不得出现任何其他语言残留。

## 1) 全局规则验收

- [ ] 切换为中文后，全站仅显示简体中文（允许保留国际通用缩写如 `Lysholm` / `IKDC` / `MMT` / `ROM` / `API Gateway`）
- [ ] 切换为英文后，全站仅显示英文（同上保留国际术语）
- [ ] 切换为巴葡后，全站仅显示巴葡（同上保留国际术语）
- [ ] 语言切换无刷新实时生效
- [ ] 刷新页面语言保持不丢失
- [ ] 关闭重开后语言保持不丢失
- [ ] 跨页面路由跳转语言保持不丢失
- [ ] 所有语言切换入口均位于页面右上角，位置和样式一致
- [ ] 三语布局无溢出、无按钮错位、无换行错乱
