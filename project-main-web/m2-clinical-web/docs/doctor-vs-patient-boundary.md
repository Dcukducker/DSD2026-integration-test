# 医生端与患者端功能边界（ACL 术后康复）

## 医生端（临床工作站）独有能力

- 临床路径与分期管理：`IA/IB/II` 分期、`Cobb` 分级、智能分型（优质/迟缓/高风险代偿）
- 专业量表：`Lysholm` 分项及总分、`IKDC`、`Tegner`
- 生物力学：`KT-1000/2000` 模拟前向位移、`H/Q Ratio`
- 风险分层：`Green/Yellow/Red/Orange`
- 临床医嘱：保护性负重等级、瘢痕管理/粘连松解
- 医疗质控：漏练/未完成占比饼图、并发症事件台账
- 医疗文档导出：《ACL术后康复中期评估报告》

## 患者端仅保留

- 任务执行与打卡
- 基础康复趋势查看
- 复诊提醒与入口
- 3D 视图查看（不含临床决策参数）

## 权限边界原则

- 患者端不展示：分期分级、风险分层算法细节、并发症记录、临床医嘱文本、医疗质控统计
- 医生端掌控：评估判定、风险分层、干预策略、病历级导出
